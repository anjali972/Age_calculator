# 🧮 Age Calculator

This is a simple **Age Calculator** web application built using **HTML**, **CSS**, and **JavaScript**. It takes a user's date of birth and calculates their current age in years, months, and days.

## 🚀 Features

- Input date of birth using a date picker
- Calculates age based on the current date
- Displays age in a clear, readable format
- Clean and responsive UI using CSS

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
